# CLAUDE.md

Personal site for Luis Merino, served by GitHub Pages from the repo root. Sub-projects live in their own folders (`kinetic/`, `terradex/`, `cr7/`, and so on).

## Design and UI work

Whenever you design, build, or restyle anything visual (a page, an app, a component, an artifact, a mockup):

- Follow the design principles below.
- For pages on the main site, read `DESIGN_SYSTEM.md` first and use its tokens. A sub-project may have its own look; check its folder for design notes and keep that look consistent within it.
- Propose design directions before building something new and large, unless the user has already picked one.
- Before saying a UI is done, run the "Concrete checks" list in `DESIGN_PRINCIPLES.md`.

## Writing

All site text follows `WRITING_STYLE.md` (no em dashes, no hype, plain direct sentences).
