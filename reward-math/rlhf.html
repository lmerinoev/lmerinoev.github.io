5.1The setup

We now have a reward model r_\phi that can score any response. RLHF, reinforcement learning from human feedback, uses it as the reward in the RL setup from Module 3. The policy {\pi_\theta} is the language model being tuned. A prompt x is the starting state, the response y is the sequence of actions, and the reward model scores the finished response. The reward model is frozen at this stage: only θ changes.

A reference model {\pi_{\mathrm{ref}}} is a frozen copy of the model from before this stage, usually the SFT model. The policy starts as an identical copy and moves away from it as training goes on.

5.2The objective

RLHF maximizes this objective (DPO paper, equation 3):

\max_{{\theta}}\ \mathbb{E}_{x \sim \mathcal{D},\ y \sim {\pi_\theta}(y \mid x)}\big[r_\phi(x, y)\big] - {\beta}\, \mathbb{D}_{\mathrm{KL}}\big[{\pi_\theta}(y \mid x)\,\big\|\,{\pi_{\mathrm{ref}}}(y \mid x)\big]
(5.1)

The first term rewards responses the reward model likes. The second term charges a price for moving away from the reference model.

5.3KL divergence

The KL divergence (Kullback-Leibler divergence) measures how different two probability distributions are:

\mathbb{D}_{\mathrm{KL}}(p \,\|\, q) = \sum_{y} p(y)\, {\log}\frac{p(y)}{q(y)}
(5.2)

It is 0 when the two distributions are identical and grows as they separate. It is not symmetric: KL(p ‖ q) usually differs from KL(q ‖ p). For a language model the sum runs over every possible response, far too many to list, so it is estimated from sampled responses.

5.4What the penalty does

Why not just maximize reward? The reward model learned from responses written by the SFT model, so its scores are only reliable for responses that look like those. Without a penalty, optimization drifts toward responses the reward model scores highly for the wrong reasons. Module 8 is about this failure. The DPO paper lists three jobs for the KL penalty: keeping the policy where the reward model is accurate, keeping its outputs varied, and stopping it from collapsing onto a single high-reward answer.

In practice the penalty is folded into the reward of each sampled response (DPO section 3; InstructGPT equation 2):

r(x, y) = r_\phi(x, y) - {\beta}\big({\log}{\pi_\theta}(y \mid x) - {\log}{\pi_{\mathrm{ref}}}(y \mid x)\big)
(5.3)

The bracket is a one-sample estimate of the KL term: averaged over responses drawn from the policy, it equals the KL divergence in equation 5.1. InstructGPT applied this penalty at every token. Its full objective also mixed in the pretraining loss (its “PPO-ptx” models) to limit losses on standard benchmarks.

5.5PPO

The reward in equation 5.3 could be optimized with REINFORCE from Module 3. RLHF has mostly used proximal policy optimization (PPO; Schulman et al., 2017) instead, because it is more stable. PPO samples a batch of responses with the current policy, then takes several gradient steps on that same batch. To stop those steps moving the policy too far from the version that generated the data, it compares each action's new and old probability:

\rho_t({\theta}) = \frac{{\pi_\theta}(a_t \mid s_t)}{\pi_{\theta_{\mathrm{old}}}(a_t \mid s_t)}
(5.4)

This is the probability ratio. It is 1 before any update, above 1 if the action became more likely, below 1 if less likely. The PPO paper calls it rt(θ). It is renamed ρ (rho) here to avoid a clash with the reward r.

PPO maximizes the clipped objective (PPO paper, equation 7):

L^{\mathrm{CLIP}}({\theta}) = \hat{\mathbb{E}}_t\Big[\min\big(\rho_t({\theta})\,\hat{A}_t,\ \mathrm{clip}\big(\rho_t({\theta}),\, 1-\epsilon,\, 1+\epsilon\big)\,\hat{A}_t\big)\Big]
(5.5)

If an action had a positive advantage, the objective stops rewarding increases in its probability once ρ passes 1 + ε. If the advantage was negative, it stops rewarding decreases once ρ falls below 1 − ε. Either way, one batch cannot drag the policy far.

To estimate advantages, PPO trains a second network alongside the policy, a value function that predicts the expected return from a state. It plays the role of the baseline in Module 3. InstructGPT initialized its value function from the reward model.

Clipping

Take ε = 0.2. Each term of equation 5.5 is the smaller of the unclipped and clipped products:

  1. Â = 2, ρ = 1.5 min(1.5 × 2, 1.2 × 2) = min(3.0, 2.4) = 2.4
  2. Â = 2, ρ = 1.1 min(1.1 × 2, 1.1 × 2) = 2.2 (inside the range, no clipping)
  3. Â = −2, ρ = 0.5 min(0.5 × −2, 0.8 × −2) = min(−1.0, −1.6) = −1.6

In the first case, raising ρ past 1.2 earns nothing more, so there is no gradient pushing it further. In the third, lowering ρ past 0.8 earns nothing more either.

5.7Exercises

  1. What happens if β = 0?

    Only the reward counts. Nothing holds the policy near the reference model, so it is free to drift to responses the reward model overrates. Module 8 shows where that leads.

  2. What is the KL divergence when the policy equals the reference model?

    0, because every log ratio is log 1 = 0. The objective is then just the reference model's expected reward.

  3. In the clipping example with Â = 2, what is the term at ρ = 1.1, and why is it not clipped?

    2.2. The ratio 1.1 is inside the range 0.8 to 1.2, so the clipped and unclipped products are equal.

  4. PPO already limits how far the policy moves from πθ_old. Why does RLHF also penalize distance from πref?

    They do different jobs. Clipping limits each update relative to the policy that sampled the batch, which keeps optimization stable. The KL penalty limits the total drift from the SFT model, where the reward model's scores can be trusted. Many small steps could otherwise add up to a large drift.

  5. In the penalty example, above what value of β does the reference policy win?

    Where 0.800 − β × 0.0851 = 0.650, so β = 0.150 / 0.0851 ≈ 1.76.
