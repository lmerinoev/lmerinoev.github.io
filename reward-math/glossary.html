Glossary

Every term defined in the modules, in alphabetical order, with a link to the section that introduces it. There are 72 terms.

A

Action
A choice the agent makes. For a language model, the next token.Introduced in Module 3, section 3.1: Agents and environments
Activation function
A fixed function applied to a neuron's weighted sum, which lets networks represent curved relationships.Introduced in Module 1, section 1.1: A model is a function with dials
Advantage
How much better an action turned out than expected: return minus baseline.Introduced in Module 3, section 3.6: Baselines and advantages
Agent
The learner and decision maker in reinforcement learning.Introduced in Module 3, section 3.1: Agents and environments

B

Backpropagation
Computing the gradient for every parameter by applying the chain rule backwards from the loss, reusing shared work.Introduced in Module 1, section 1.4: Backpropagation
Baseline
An estimate of the usual return, subtracted from the actual return to reduce noise in policy gradient updates.Introduced in Module 3, section 3.6: Baselines and advantages
Best-of-n sampling
Drawing n responses and keeping the one the reward model scores highest.Introduced in Module 8, section 8.2: Measuring it
Bias
A parameter that is added after the weighted inputs, shifting the result.Introduced in Module 1, section 1.1: A model is a function with dials
Bradley-Terry model
A model of pairwise choices: the probability that A beats B is σ(score of A − score of B).Introduced in Module 4, section 4.2: Bradley-Terry

C

Chain rule
The rule that the derivative through a chain of functions is the product of the derivatives of each link.Introduced in Module 1, section 1.4: Backpropagation
Context
The tokens before the current position, written x<t.Introduced in Module 2, section 2.2: Predicting the next token
Cross-entropy loss
The sum of −log p over the correct tokens. Small when the model gives the actual text high probability.Introduced in Module 2, section 2.4: The cross-entropy loss

D

Derivative
How fast a function's output changes as its input changes: the slope at a point.Introduced in Module 1, section 1.3: Gradients point uphill
Direct preference optimization (DPO)
Training a policy directly on preference pairs with a Bradley-Terry loss on implicit rewards, with no separate reward model and no RL loop.Introduced in Module 6, section 6.1: The idea
Discount factor (γ)
A number between 0 and 1 that makes later rewards count less in the return.Introduced in Module 3, section 3.2: Return

E

Environment
Everything the agent interacts with. It supplies states and rewards.Introduced in Module 3, section 3.1: Agents and environments
Episode
One complete run from start to finish.Introduced in Module 3, section 3.1: Agents and environments
Expected return
The average return a policy gets, J(θ). Reinforcement learning tries to maximize it.Introduced in Module 3, section 3.3: Expected return
Expected value (𝔼)
The average of a quantity over all possible outcomes, weighted by their probabilities.Introduced in Module 3, section 3.3: Expected return

G

Goodhart's law
When a measure becomes a target, it stops being a good measure.Introduced in Module 8, section 8.1: Proxies and Goodhart's law
Gradient
The list of partial derivatives of the loss with respect to every parameter. It points in the direction that increases the loss fastest.Introduced in Module 1, section 1.3: Gradients point uphill
Gradient descent
Improving parameters by repeatedly stepping a small distance against the gradient.Introduced in Module 1, section 1.5: Gradient descent
GRPO
Group relative policy optimization: a policy gradient method that uses the mean and spread of rewards within a group of samples as its baseline.Introduced in Module 7, section 7.4: Comparing within a group

I

Implicit reward
In DPO, β·log(π_θ(y|x)/π_ref(y|x)): a reward defined by how much the tuned model raises a response's probability.Introduced in Module 6, section 6.4: The implicit reward

K

KL divergence
A measure of how different two probability distributions are. Zero when they are identical.Introduced in Module 5, section 5.3: KL divergence
KL penalty
A term −β·KL that lowers the objective as the tuned model moves away from the reference model.Introduced in Module 5, section 5.4: What the penalty does

L

Language model
A model that takes a sequence of tokens and outputs a probability for each possible next token.Introduced in Module 2, section 2.1: Text as tokens
Learning rate (η)
How large a step gradient descent takes.Introduced in Module 1, section 1.5: Gradient descent
Log probability
The natural logarithm of a probability. Always zero or negative; sums of log probabilities replace products of probabilities.Introduced in Module 2, section 2.4: The cross-entropy loss
Logit
A raw score the network outputs for one option, before softmax turns the scores into probabilities.Introduced in Module 2, section 2.3: Logits and softmax
Loss
A single number measuring how wrong a model's outputs are. Training tries to make it small.Introduced in Module 1, section 1.2: A loss measures the mistake
Loss function
The formula that computes the loss from the model's outputs and the correct answers.Introduced in Module 1, section 1.2: A loss measures the mistake

M

Model
A function that turns an input into an output, with behavior set by adjustable numbers.Introduced in Module 1, section 1.1: A model is a function with dials

N

Neural network
A model built from many simple units arranged in layers, where each layer's outputs feed the next.Introduced in Module 1, section 1.1: A model is a function with dials
Neuron
The basic unit of a neural network: multiply inputs by weights, add a bias, apply an activation function.Introduced in Module 1, section 1.1: A model is a function with dials
Next-token prediction
The pretraining task: predict each token from the tokens before it.Introduced in Module 2, section 2.2: Predicting the next token

O

Overoptimization
The pattern where the proxy reward keeps rising during optimization while true quality rises and then falls.Introduced in Module 8, section 8.1: Proxies and Goodhart's law

P

Parameters
The adjustable numbers inside a model. Training changes them. Written θ (or φ for a reward model).Introduced in Module 1, section 1.1: A model is a function with dials
Partial derivative
The derivative with respect to one input while every other input is held fixed. Written with ∂.Introduced in Module 1, section 1.3: Gradients point uphill
Partition function Z(x)
The sum that rescales a set of positive weights so they add up to 1.Introduced in Module 6, section 6.2: The best policy has a formula
Policy (π)
The rule an agent uses to choose actions. π(a | s) is the probability of action a in state s. A language model is a policy.Introduced in Module 3, section 3.1: Agents and environments
Policy gradient
The gradient of expected return with respect to a policy's parameters, written so it can be estimated from samples.Introduced in Module 3, section 3.4: The policy gradient
Preference pair
A prompt with two responses and a record of which one a rater preferred.Introduced in Module 4, section 4.1: The idea
Pretraining
The first and largest training stage, in which a language model learns next-token prediction on a very large body of text.Introduced in Module 2, section 2.4: The cross-entropy loss
Probability distribution
A set of probabilities, each between 0 and 1, covering every possible outcome and adding up to 1.Introduced in Module 2, section 2.1: Text as tokens
Probability ratio (ρ)
The new policy's probability of an action divided by the old policy's probability.Introduced in Module 5, section 5.5: PPO
Proximal policy optimization (PPO)
A policy gradient method that takes several steps on each batch of samples while clipping how far the policy can move.Introduced in Module 5, section 5.5: PPO
Proxy reward
A measurable stand-in for the real goal, such as a reward model standing in for human judgment.Introduced in Module 8, section 8.1: Proxies and Goodhart's law

R

Reference model (π_ref)
A frozen copy of the model from before tuning, usually the SFT model. The KL penalty measures distance from it.Introduced in Module 5, section 5.1: The setup
REINFORCE
The basic policy gradient algorithm: after an episode, raise the log probability of each action in proportion to the return that followed it.Introduced in Module 3, section 3.5: REINFORCE
Reinforcement learning (RL)
Learning which actions to take from a reward signal rather than from correct answers.Introduced in Module 3, section 3.1: Agents and environments
Return
The total (possibly discounted) reward collected over a trajectory.Introduced in Module 3, section 3.2: Return
Reward
A number the environment returns that says how good an outcome was.Introduced in Module 3, section 3.1: Agents and environments
Reward hacking
Earning high reward by exploiting flaws in the reward rather than by doing the task better.Introduced in Module 8, section 8.1: Proxies and Goodhart's law
Reward model
A neural network that reads a prompt and a response and outputs one number, trained so preferred responses score higher.Introduced in Module 4, section 4.1: The idea
RLHF
Reinforcement learning from human feedback: tuning a language model with RL against a reward model trained on human preferences.Introduced in Module 5, section 5.1: The setup
RLVR
Reinforcement learning with verifiable rewards.Introduced in Module 7, section 7.1: Rewards you can check

S

Sigmoid (σ)
The function σ(z) = 1/(1 + e^(−z)), which maps any number to a value between 0 and 1.Introduced in Module 1, section 1.1: A model is a function with dials
Softmax
The function that turns a list of scores into probabilities: exponentiate each, then divide by the total.Introduced in Module 2, section 2.3: Logits and softmax
Sparse reward
A reward that is zero for most attempts, so most samples give no learning signal.Introduced in Module 7, section 7.3: Checking an answer
State
What the agent observes at a time step. For a language model, the prompt plus the tokens written so far.Introduced in Module 3, section 3.1: Agents and environments
Supervised fine-tuning (SFT)
Training a pretrained model on example responses written by people, using the same cross-entropy loss as pretraining.Introduced in Module 4, section 4.1: The idea
Sycophancy
Telling users what they appear to want to hear, such as agreeing with a mistaken belief, instead of what is accurate.Introduced in Module 8, section 8.4: From rater preferences to writing habits

T

Token
A chunk of text, often a word or part of a word, that a language model reads and writes.Introduced in Module 2, section 2.1: Text as tokens
Tokenizer
The program that splits text into tokens.Introduced in Module 2, section 2.1: Text as tokens
Training step
One update of the parameters.Introduced in Module 1, section 1.5: Gradient descent
Trajectory (τ)
The sequence of states, actions and rewards from one run.Introduced in Module 3, section 3.1: Agents and environments

V

Value function
A learned estimate of the expected return from a state, used to compute advantages.Introduced in Module 5, section 5.5: PPO
Verifiable reward
A reward computed by a verifier: 1 when the check passes, otherwise 0.Introduced in Module 7, section 7.1: Rewards you can check
Verifier
A program that checks a response, for example by comparing a final answer or running tests.Introduced in Module 7, section 7.1: Rewards you can check
Vocabulary
The fixed list of every token a model knows.Introduced in Module 2, section 2.1: Text as tokens

W

Weight
A parameter that multiplies an input.Introduced in Module 1, section 1.1: A model is a function with dials
