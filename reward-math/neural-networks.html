1.1A model is a function with dials

A model is a function that turns an input into an output. A neural network is a model built from many simple units arranged in layers. Its behavior depends on a large set of adjustable numbers called parameters. Training means searching for parameter values that make the outputs good.

The smallest useful example is a single neuron. It multiplies its input x by a weight {w}, adds a bias {b}, and passes the result through an activation function. Here the activation function is the sigmoid, written σ, which squashes any number into the range 0 to 1.

\hat{y} = {\sigma}({w}\,{x} + {b}), \qquad {\sigma}(z) = \frac{1}{1 + e^{-z}}
(1.1)

σ(0) = 0.5. Large positive inputs give values near 1 and large negative inputs give values near 0. A real network repeats this unit millions or billions of times, with the outputs of one layer feeding the next. Every idea in this module already shows up in one neuron.

1.2A loss measures the mistake

To improve the model we need one number that says how wrong it is. That number is the loss, and the formula that computes it is the loss function. Lower is better. A common choice, for one example whose correct answer is y, is the squared error:

\mathcal{L}({\theta}) = (\hat{y} - y)^2
(1.2)

Squaring makes every mistake positive and punishes big mistakes much more than small ones. When training on many examples, the loss is the average over all of them.

1.3Gradients point uphill

The derivative of a function says how fast its output changes when you nudge its input: the slope. A partial derivative, written with ∂, does the same for one input while holding the others fixed. Collect the partial derivatives of the loss with respect to every parameter and you get the gradient:

\nabla_{{\theta}}\mathcal{L} = \left(\frac{\partial \mathcal{L}}{\partial {w}},\ \frac{\partial \mathcal{L}}{\partial {b}}\right)
(1.3)

The gradient points in the direction that increases the loss fastest. Its size says how steep that direction is.

1.4Backpropagation

The loss depends on a parameter through a chain of steps: {w} affects z, z affects \hat{y}, and \hat{y} affects the loss. The chain rule from calculus says the derivative along a chain is the product of the derivatives of each link:

\frac{\partial \mathcal{L}}{\partial {w}} = \underbrace{2(\hat{y} - y)}_{\partial \mathcal{L} / \partial \hat{y}} \cdot \underbrace{{\sigma}(z)\big(1 - {\sigma}(z)\big)}_{\partial \hat{y} / \partial z} \cdot \underbrace{{x}}_{\partial z / \partial {w}}
(1.4)

Backpropagation is the chain rule applied to a whole network in an efficient order. It runs the network forward to get the loss, then works backward from the loss, computing each link once and reusing it for every parameter further back. One backward pass gives the gradient for all parameters, at roughly the cost of one forward pass.

1.5Gradient descent

Gradient descent uses the gradient to improve the parameters a little at a time. The gradient points uphill, so step the other way:

{\theta} \leftarrow {\theta} - \eta\,\nabla_{{\theta}}\mathcal{L}({\theta})
(1.5)

The learning rate η sets the step size. Too small and training crawls. Too large and a step can overshoot the low point. Each update is one training step. Training a language model is this same loop, repeated over an enormous number of examples, with backpropagation computing the gradient each time.

1.6A worked example

One neuron and one training example: input x = 2, correct answer y = 1. Start with {w} = 0.5, {b} = 0 and learning rate \eta = 0.5.

  1. forward z = 0.5 × 2 + 0 = 1.0
  2. ŷ = σ(1.0) = 1 / (1 + e−1) = 0.7311
  3. loss = (0.7311 − 1)² = 0.0723
  4. backward ∂L/∂ŷ = 2 × (0.7311 − 1) = −0.5379
  5. ∂ŷ/∂z = 0.7311 × (1 − 0.7311) = 0.1966
  6. ∂L/∂z = −0.5379 × 0.1966 = −0.1058
  7. ∂L/∂w = −0.1058 × 2 = −0.2115 ∂L/∂b = −0.1058
  8. update w = 0.5 − 0.5 × (−0.2115) = 0.6058
  9. b = 0 − 0.5 × (−0.1058) = 0.0529
  10. check z = 1.2644, ŷ = 0.7798, loss = 0.0485

Both partial derivatives were negative, so both parameters went up, and the loss fell from 0.0723 to 0.0485. Keep stepping in the figure below.

1.7Exercises

  1. The partial derivative ∂L/∂w is positive. Does gradient descent make w larger or smaller?

    Smaller. Equation 1.5 subtracts η times the gradient, so a positive gradient lowers w. A positive gradient means that increasing w would increase the loss.

  2. Compute σ(0) and the slope σ(0)(1 − σ(0)).

    σ(0) = 1/(1 + 1) = 0.5, and the slope is 0.5 × 0.5 = 0.25. The sigmoid is steepest at 0 and flattens out on both sides.

  3. In the worked example, why did b change by half as much as w?

    The last link of the chain is ∂z/∂w = x = 2 for w but ∂z/∂b = 1 for b. Everything else in the chain is shared, so w's gradient is twice b's.

  4. Why compute gradients with backpropagation instead of nudging each parameter and re-running the network?

    Nudging needs an extra forward pass for every parameter, which means billions of passes for a large model. Backpropagation reuses the shared links of the chain and gets every gradient from one backward pass.
