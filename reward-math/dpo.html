6.1The idea

RLHF trains two models in sequence: a reward model, then a policy against it with RL. Direct preference optimization (DPO; Rafailov et al., 2023) reaches the same target with one model and one loss that looks like the reward model loss from Module 4. There is no sampling from the policy during training, no value function, and no PPO.

The route has three steps: solve the RLHF objective exactly, rearrange the solution to express the reward in terms of the policy, and substitute that into Bradley-Terry.

6.2The best policy has a formula

For a fixed reward function r, the objective in equation 5.1 has an exact solution (DPO equation 4):

{\pi_r}(y \mid x) = \frac{1}{Z(x)}\,{\pi_{\mathrm{ref}}}(y \mid x)\,{\exp}\Big(\frac{1}{{\beta}}\, r(x, y)\Big)
(6.1)
Z(x) = \sum_{y} {\pi_{\mathrm{ref}}}(y \mid x)\,{\exp}\Big(\frac{1}{{\beta}}\, r(x, y)\Big)
(6.2)

Start from the reference model, multiply each response's probability by exp(r/β), then divide by the total so the probabilities add up to 1 again. The total is the partition function Z(x). It sums over every possible response, which is impossible to compute for a language model. That is why RLHF uses RL instead of applying this formula directly.

6.3Turning it around

Take the log of equation 6.1 and solve for r (DPO equation 5):

r(x, y) = {\beta}\,{\log}\frac{{\pi_r}(y \mid x)}{{\pi_{\mathrm{ref}}}(y \mid x)} + {\beta}\,{\log} Z(x)
(6.3)

Any reward can be written in terms of its own optimal policy, plus a term that depends only on the prompt. Now substitute this into Bradley-Terry. Bradley-Terry only uses the difference r(x, yw) − r(x, yl), and both responses share the prompt x, so the β log Z(x) terms cancel. The quantity that could not be computed disappears.

6.4The implicit reward

So DPO defines a reward directly from the policy being trained (DPO section 4):

\hat{r}_{{\theta}}(x, y) = {\beta}\,{\log}\frac{{\pi_\theta}(y \mid x)}{{\pi_{\mathrm{ref}}}(y \mid x)}
(6.4)

This is the implicit reward: β times how much more likely the tuned model makes a response than the reference does, on a log scale. It is positive if the response became more likely and negative if less. The language model is its own reward model, which is where the paper's title, “Your Language Model is Secretly a Reward Model”, comes from.

6.5The DPO loss

Put the implicit reward into the reward model loss from equation 4.4 (DPO equation 7):

\mathcal{L}_{\mathrm{DPO}}({\pi_\theta}; {\pi_{\mathrm{ref}}}) = -\mathbb{E}_{(x, {y_w}, {y_l}) \sim \mathcal{D}}\left[{\log}\,{\sigma}\left({\beta}\,{\log}\frac{{\pi_\theta}({y_w} \mid x)}{{\pi_{\mathrm{ref}}}({y_w} \mid x)} - {\beta}\,{\log}\frac{{\pi_\theta}({y_l} \mid x)}{{\pi_{\mathrm{ref}}}({y_l} \mid x)}\right)\right]
(6.5)

Training needs only the preference dataset and the log probabilities that πθ and πref assign to each response, which one forward pass of each model provides. The DPO paper shows that the gradient raises the likelihood of yw, lowers that of yl, and weights each pair by how wrongly the implicit reward currently ranks it.

6.6Worked examples

The optimal policy

Use the three responses from Module 5, with reference probabilities 0.5, 0.3, 0.2 and rewards 1.0, 0.5, 0. At β = 0.5:

  1. weights 0.5 × e2 = 3.6945 0.3 × e1 = 0.8155 0.2 × e0 = 0.2000
  2. Z(x) 3.6945 + 0.8155 + 0.2000 = 4.710
  3. π* (0.784, 0.173, 0.042)
  4. objective E[r] − β·KL = 0.871 − 0.5 × 0.192 = 0.775

That beats the tuned policy from Module 5, which scored 0.757 at β = 0.5. The best objective value also equals β log Z(x) = 0.5 × log 4.710 = 0.775. That is not a coincidence: substitute equation 6.3 into equation 5.1 and every other term cancels.

The DPO loss on one pair

A whole response's log probability is the sum of its tokens' log probabilities (equation 2.1, in log form), so these numbers are large and negative. Take β = 0.1:

log πreflog πθimplicit reward
preferred yw−12.0−11.00.1 × (−11.0 + 12.0) = 0.10
rejected yl−11.0−11.50.1 × (−11.5 + 11.0) = −0.05
  1. gap 0.10 − (−0.05) = 0.15
  2. loss −log σ(0.15) = −log 0.537 = 0.621
  3. start (πθ = πref) gap 0, loss −log 0.5 = 0.693

Training has made the preferred response more likely and the rejected one less likely, relative to the reference, and the loss has fallen from 0.693 to 0.621.

6.7Exercises

  1. At the start of training πθ = πref. What is the DPO loss for every pair?

    Both implicit rewards are β log 1 = 0, so the loss is −log σ(0) = log 2 ≈ 0.693.

  2. Why does Z(x) not appear in the DPO loss?

    It enters both rewards in the Bradley-Terry difference as the same term β log Z(x), because both responses answer the same prompt. It cancels.

  3. Can the DPO loss fall while the preferred response becomes less likely?

    Yes. Only the gap between implicit rewards matters. If log πθ(yw) drops to −12.5 and log πθ(yl) drops to −13.0, the implicit rewards are −0.05 and −0.20, the gap is still 0.15, and the loss is still 0.621.

  4. What does a smaller β do?

    It weakens the pull toward the reference model. In equation 6.1 a small β makes the boost exp(r/β) stronger, so the optimal policy moves further from πref.

  5. Does DPO sample new responses from the policy during training?

    No. It trains on a fixed dataset of preference pairs. RLHF with PPO samples new responses from the current policy at every step. The RLHF book discusses this difference as offline versus online data.
